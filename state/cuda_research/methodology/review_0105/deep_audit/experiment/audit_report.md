# Experimental design audit, 2026-10-13

Scope: independent review of methodology 0080–0104, current runner/task/scheduler, and CPU tests of exact production task logic. No production source, queue, CUDA build, training process or simulator state was changed. Test code and raw results live beside this report.

## Direct findings

1. A current 65,536-transition run with 128 agents contains 512 control steps per lane: 10.24 seconds at 50 Hz, 16 collection/update batches, 192 Adam steps, and at most one complete 500-step episode per lane absent earlier failures. This is a small learning probe, not convergence. Repeated defaults carry weights but reconstruct Adam and ground-start every child (scheduler lines 60–67 and 101–102, runner lines 91–106, 241–303). Prior reviews correctly identify this limitation; it should remain prominent instead of counting trials as equal evidence.
2. Requested obstacle-free still-air reset removes every sampled domain variable: boxes emptied, wind zeroed, target reset to the same carrier XY and height. Corrected ground geometry, q/rates, motors, masses and parameters are fixed (task lines 218–245). CPU factory substitution with a no-op fake simulator invoked the unmodified production reset. All relevant state tensors and 98 observations had exactly the same SHA256 for seeds 51011, 51012, 51013; all 8 agents were identical. These 24 deterministic evaluations are one environment condition. Training-seed comparisons can still test optimizer/action randomness, but they do not establish environmental reliability or a binomial 24-flight success rate.
3. Evaluation is only 250 steps (5 s), while actual version-correct longer probes in reviews 0088 and 0095 escaped after 5.2–8.56 s. The endpoint can look good just before inevitable failure. Task.send resets position/velocity/motors on done, so final error after a failure is a reset-state metric. Current rank puts failures first and review history preserves this correctly. Further promotion needs first-failure-stopping longer trajectories and pre-reset observations.
4. A flag corner case exists: simultaneous real failure and normal 500-step timeout produce done=True, truncated=True, failed=3. Evaluator counts done & ~truncated, so it omits that actual failure. CPU production mock reproduced it; the proposed version2 helper gives failure priority by clearing truncated whenever failed != 0. Eighteen scalar cases plus a mixed-batch region-cutoff case pass. The current 250-step evaluation is unaffected. This is a separately versioned flag fix, NOT evidence for the present 5-second hover failure and NOT a factor to slip into the learner experiment.
5. Default continuation remains observation1/reward14. Candidate observation2/reward15 probes are explicitly warm-started from 759best and do not feed the default pointer. Hence many intervening defaults do not further train the improved altitude architecture. This is intentional conservative research policy in reviews0092/0093, but it means the number of elapsed default trials is not an observation2 learning curve.
6. GAE gamma .995, lambda .95 gives geometric decay 1/(1-gamma*lambda)=18.26 steps (~0.365 s), and fragments are 32 steps (0.64 s). This does not prove a credit bug. Reviews0098–0102 already show target-height exposure and directionally sensible actual raw/normalized credit. Older longer-fragment and lambda tests are genuine counterevidence to a universal temporal cure.

## Recommended next controlled learning test

Parent's proposed 2x2 is appropriate: current task reward15/collective observation2/physics5/reset3, same 759best function and fresh Adam, seeds70401–70403, transitions65,536 versus262,144 crossed with valid-cell mask1 versus2. Keep 128 agents, batch4096, horizon32, LR3e-6, all physical/success versions unchanged. The learner audit identifies the last fragment column as a bootstrap-only cell: kernel returns zero advantage there. Mask2 should exclude it from advantage normalization and policy/value reductions while keeping last values for bootstrapping. That is 3.125% of cells, so fixing it is meaningful correctness work but does not imply a large performance gain.

Why this is different: legacy queuev018/review0028 varied fragment length on reward2/physics1; queuev026/review0044 varied duration on reward7/physics1. Neither tests current reward15/observation2/physics5 or the newly identified bootstrap-cell issue. Keep those failures as counterevidence rather than saying longer training always works or was never tried. A factorial experiment separates duration, mask correctness, and their interaction; changing only one candidate to both factors would confound attribution.

Pre-register controls: 12 frozen arms; each starts the same policy function and seed-specific RNG. For every mask/seed, compare the 65k arm final tensors with its long-arm 65k checkpoint. Verify equality rather than assume it: total-step-dependent annealing, diagnostics or RNG consumption could alter prefixes. Periodic RNG-restored evaluations should preserve sampling, but test actual tensors. Require achieved steps; 600 seconds is a bound, not proof262k completed. If censored, analyze actual prefixes and mark planned duration comparison incomplete.

Primary evidence: crashes/first failure, deterministic takeoff, unchanged 1s zone hover, carrier speed/XY/height trajectories, and regression between initial/periodic/final. Keep selected initial checkpoints distinct from learning. Reward magnitude and final altitude crossing do not promote. Reject an arm with added failures/lost takeoff; reject hover claims without 1-second hold followed by longer uninterrupted survival. Paired gains on one fixed still-air reset remain provisional. Four complete maximum-length episodes per lane at262k are still modest exposure and are not convergence proof.

A separate high-value diagnostic if needed is recovery from real late-rollout states. The 98 observations contain full particle positions/velocities, quaternion/rates, motors and goal, sufficient to reconstruct these fixed-domain states. Branch actual near-target/slow and near-target/fast states into identical fixed-policy closed-loop rollouts and stop first failure. This isolates local stabilization from ground launch and differs from the previous ideal taut warm-start experiment. It does not add a helper/controller or certify physical fidelity.
